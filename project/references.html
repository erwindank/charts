About This Project

This is a music charts website that allows you to track and analyze your music listening data. The application stores data locally in your browser using localStorage, making it fast and privacy-friendly.

Features

  • Dashboard with statistics and recent plays
  • Dynamic charts with Top 10, 20, or 100 songs
  • Manual data entry via form
  • Bulk import via CSV or JSON files
  • Automatic data aggregation by song and artist
  • Excel error filtering (#NAME?, #VALUE!, etc.)
  • Datetime format conversion
  • Data export functionality
  • Responsive design for mobile and desktop

Data Format

Required Fields

  • song: The title of the song
  • artist: The artist name
  • plays: Number of plays (numeric)
  • datetime: When the song was played
  • album: The album name (optional)

Supported Date Formats

The application automatically converts the following datetime format:

11 Dec 2025, 20:52

This is converted to ISO 8601 format for consistent storage and sorting.

CSV File Format

When uploading CSV files, ensure the first row contains headers. The application supports the following format:

song,plays,datetime,artist,album
Shape of You,145,11 Dec 2025, 20:52,Ed Sheeran,Divide
Blinding Lights,230,12 Dec 2025, 14:30,The Weeknd,After Hours
Someone Like You,89,10 Dec 2025, 09:15,Adele,21

JSON File Format

JSON files should contain an array of song objects:

[
  {
    "song": "Shape of You",
    "plays": 145,
    "datetime": "11 Dec 2025, 20:52",
    "artist": "Ed Sheeran",
    "album": "Divide"
  },
  {
    "song": "Blinding Lights",
    "plays": 230,
    "datetime": "12 Dec 2025, 14:30",
    "artist": "The Weeknd",
    "album": "After Hours"
  }
]

Data Aggregation

The application automatically aggregates plays by combining songs with the same title and artist. This means if you have multiple entries for "Shape of You" by "Ed Sheeran", they will be combined into a single chart entry with the total plays summed up.

Example:

  • Entry 1: "Shape of You" by "Ed Sheeran" - 145 plays
  • Entry 2: "Shape of You" by "Ed Sheeran" - 89 plays
  • Result: "Shape of You" by "Ed Sheeran" - 234 total plays

Excel Error Filtering

The application automatically filters out entries that contain Excel errors. The following error types are detected and removed:

  • #NAME? - Name error
  • #VALUE! - Value error
  • #REF! - Reference error
  • #DIV/0! - Division by zero error
  • #N/A - Not available error
  • #NULL! - Null error
  • #NUM! - Number error

Privacy & Data Storage

All your music data is stored locally in your browser using localStorage. This means:

  • Your data never leaves your device
  • No server-side storage or tracking
  • Data persists between sessions
  • Clearing browser data will remove all stored information
  • Data is specific to this browser and device

Browser Compatibility

This application works best on modern browsers that support:

  • HTML5
  • CSS3 (Grid, Flexbox, Variables)
  • ES6+ JavaScript
  • localStorage API
  • File API

Recommended browsers: Chrome, Firefox, Safari, Edge (latest versions)

Tips & Best Practices

  • Regularly export your data as a backup
  • Use consistent naming for artists and songs
  • Clean your data before importing to avoid duplicates
  • Check for Excel errors in your source files
  • Use the correct datetime format for accurate sorting
  • Monitor localStorage usage (typically 5-10MB limit)
