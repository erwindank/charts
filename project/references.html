Technical Resources

  • HTML5 - Semantic markup with modern standards
  • CSS3 - Custom properties, Flexbox, and Grid layout
  • Vanilla JavaScript - No frameworks, pure ES6+ features
  • localStorage API - Client-side data persistence
  • File API - CSV and JSON file processing

Design Features

  • Responsive Design - Mobile-first approach with breakpoints at 600px, 900px, and 1200px
  • Dark Theme - Eye-friendly dark color scheme for extended viewing
  • Smooth Animations - CSS transitions and keyframe animations
  • Accessibility - Semantic HTML and proper contrast ratios
  • Performance - Font preloading and lazy loading where applicable

Data Handling

  • CSV Format: song,plays,datetime,artist,album
  • DateTime Format: "11 Dec 2025, 20:52" (converted to ISO 8601)
  • Excel Error Filtering: Removes #NAME?, #REF!, #VALUE!, etc.
  • Song Aggregation: Combines entries by song + artist combination
  • XSS Prevention: All user-generated content is escaped
